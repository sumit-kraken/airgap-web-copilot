🦙 How to Get & Run Local Ollama

Ollama is a lightweight tool that runs open-source LLMs (like Llama 3.2, Gemma 2, and Qwen 2.5) locally on your PC. It enables pure offline execution with up to 128,000 tokens of context.

1. Download & Install Ollama
• Windows: Download OllamaSetup.exe and run installer.
• macOS: brew install ollama or download from ollama.com
• Linux: curl -fsSL https://ollama.com/install.sh | sh
2. Download (Pull) a Model
Open PowerShell or Terminal and run:
ollama pull llama3.2
Other options: ollama pull gemma2:2b or ollama pull qwen2.5:7b
3. Start the Ollama Service
Ollama runs automatically in your system tray. If ever stopped, run:
ollama serve
Daemon URL: http://localhost:11434
